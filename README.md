## SQALOGY API AUTOMATON PROJECT WITH Newman Reporting

## About this project
This is employee api automation project.THis project is faclated to create Employee,update employee,Get employee list with diffrent parameter.Here we have create automation and generate a newman report.

## Pre-reuqisite
- Nodejs

## Tools & Technology
- postman
- visual studion code

## API Documentation [Employee API Documentation](https://documenter.getpostman.com/view/25113210/2sB3BLhSC1#intro)

## How To run this Project

**Clone Project**
``` bash
https://github.com/khundakerfaisal/SQALOGYB3ApiAutomationWithNewmanReporting.git
```
**Hit The command**
``` bash
npm init -y
```
``` bash
npm i newman
```
``` bash
npx newman run [collection] -e ["enviornment"]
```
``` bash
npm i newman-reporter-htmlextra
```
``` bash
node ./report.js
```
